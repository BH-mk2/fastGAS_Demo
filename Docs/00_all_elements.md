# 要素の洗い出し

- アクション
  - 攻撃
  - 防御
  - 弾き
    - 防御し始めの数フレーム、相手の攻撃を完全に防御して相手の体幹を大きく削る
  - 特殊攻撃
    - 体幹が最大値になった敵のHPを一気に０にする攻撃
  - 回避
  - ジャンプ
  - ロックオン
    - カメラが相手を追い続ける機能
  - アイテム使用
  - インタラクト
    - 会話、鍵を開ける等
- パラメータ
  - 体力値
  - 体幹値
  - 体幹削り値
    - 値が大きくなるほど相手の体幹を大きく削れる
  - 体幹防御値
    - 値が大きくなるほど自分の体幹が削れる時の値を減少させる
- ギミック
  - ドア(鍵と対になる要素)
    - ボスと戦うエリアの手前に配置
- アイテム
  - 鍵(ドアと対になる要素)
  - 回復薬
    - 使うことで体力を一定量回復させる
  - 体幹削り値増加
    - 使うことで一定時間体幹削り値を上昇させる
  - 体幹防御値増加
    - 使うことで一定時間体幹防御値を上昇させる
- ステージ数
  - 1
- ボス数
  - 1
