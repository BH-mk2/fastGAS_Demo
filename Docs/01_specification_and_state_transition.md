## 必要な仕様
- 先行入力
  - コンボ攻撃に必要
- キャンセル
  - スムーズな他モーションへの遷移に必要
  - 振り始めと振り終わりでキャンセルできるアクションを異なるものに設定できる必要がある
    - ex)攻撃の降り始めは攻撃でのキャンセルは不可だが、ガードや回避は可能
- 体幹最大時の特殊攻撃（忍殺）
- 無敵時間
  - 回避したときの数フレームだけ、敵の攻撃判定からスルーされるようにする
- UI
  - プレイヤーの体力ゲージ
  - プレイヤーの体幹ゲージ
  - 敵の体力ゲージ
  - 敵の体幹ゲージ
  - ボスの体力ゲージ
  - ボスの体幹ゲージ

- 攻防の数値・結果ルール
  - プレイヤーの初期体力は100、最大体力は100
  - プレイヤーの初期体幹は0、最大体幹は100
  - 直撃時：
    - 体力減少：25
    - 体幹増加：20
    - 怯みモーションあり
  - ガード時：
    - 体力減少：0
    - 体幹増加：10
  - 弾き時：
    - 体力減少：0
    - 体幹増加：0
    - 攻撃側の体幹増加：15
  - 回避（無敵）時：
    - 攻撃側の攻撃衝突判定でスルーされる

- アイテムの所持・効果ルール
  - インベントリ機能が必要
    - 鍵を設ける為
  - 消費アイテムと貴重品の種類を設ける必要がある
    - 回復薬は消費アイテム、鍵は貴重品
  - 消費アイテムには最大使用回数と残数がある
  - 回復薬は復活時に残数が最大使用回数に設定される
    - 回復薬以外の消費アイテムには適用されない
